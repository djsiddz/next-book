# Getting Started

## Purpose

`Next Book` is a personal book collection and reading tracker built with Next.js, React, TypeScript, Supabase, Tailwind CSS, and shadcn-style UI primitives.

## Local Development

1. Install dependencies with `pnpm install`.
2. Copy `example.env` to your local environment file and fill in the Supabase values required by the app.
3. Start the development server with `pnpm dev`.

## Primary Commands

- `pnpm dev` starts the local Next.js app.
- `pnpm build` creates a production build.
- `pnpm lint` runs ESLint.
- `pnpm test --runInBand` runs the Jest suite serially.
- `pnpm tsc` runs the TypeScript compiler without emitting files.
