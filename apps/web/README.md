# Next Book - Web App

This is the root of the web app. It is a Next.js 16 project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Current Features

- Capture ⚠️
  - Search by Author/Book Title/ISBN (using Google Books API)
  - Upload photo (using AI to extract book title)
  - Click photo (using AI to extract book title)
  - Voice entry (using AI to extract book title, additional details)
- Library ⚠️
  - List of books
  - Recommended Next Read (using AI to recommend based on your library)
- Profile / Settings ✅
  - Update Name, Profile Photo
  - Logout
